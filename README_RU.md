***ПРИМЕЧАНИЕ (в основном для Red Barrels):** **В дополнение** к файлам из этого репозитория у вас всё ещё должны быть **оригинальные исходные файлы и лицензионная копия игры** (для контент-файлов и т. д.). Файлы из этого репозитория предоставляются исключительно для **удобства моддинга***<p>
Если у вас есть оригинальные исходники Outlast, вы можете добавить/заменить их этими файлами

Получившийся `OLGame.exe`, вместе с `Core.upk`, `Engine.upk`, `OLGame.upk` или любыми другими (post-cook) `.upk` файлами, в которые вы добавляете UnrealScript, можно использовать для замены оригинальных файлов в **вашей лицензионной Steam-версии игры**.

## На данный момент модифицированный исходный код позволяет:

### Контент/Карты/Шейдеры

- Загружать оригинальный контент/карты/шейдеры (включая DLC)
- Загружать пользовательские карты через отдельную вкладку в главном меню (карты, отображаемые в этой вкладке, должны находиться в папке `CookedPCConsole/Mods/Persistent`)
- Cook `.upk` файлов, сохраняя текстуры и освещение в отдельных `.tfc` файлах (которые читаются из любой подпапки `CookedPCConsole`)
- Cook `.upk` файлов, сохраняя `Textures`, `CharTextures `и `Lighting` внутри каждого `.upk` (без `.tfc` файлов). Это удобно, когда не хочется таскать три отдельных `.tfc` файла ради одного `.upk`
- Добавлять пользовательский суффикс к `RefShaderCache` при куке `.upk` файлов
- Перенаправление ассетов для скриптовых пакетов (`.u`). Например, обновлённые скрипты из `OLGame.u` теперь имеют приоритет над оригинальным `OLGame.upk`, а порядок загрузки следующий: скрипт `.u` -> `.upk`, на который ссылается группа (например, `menuassets.upk`) -> оригинальный `OLGame.upk`

### Мультиплеер (бета)

- Подключаться к [OpenOL-Relay](https://github.com/ShyKiss/OpenOL-Relay) и играть в мультиплеер
- Влиять на миры других клиентов (Двери/Триггеры/Враги/Катсцены)
- Запускать сервер прямо из игры (встроенный relay)

### Новые консольные команды

- `Reload` перезагружает текущий чекпоинт
- `SpawnEnemy <Enemy> <Weapon> <ShouldAttack>` спавнит врага с указанным оружием и управлением атакой
- `ToggleSmoothCamera` переключает настройку плавной камеры
- `ToggleUnlockDoors` переключает игнорирование игроком запертых/заблокированных дверей
- `ToggleAllowGhostDoors` переключает возможность выполнять глитч «призрачная дверь» (например, для спидранов)
- `MaxFPS <Number>` алиас для команды `Set Engine MaxSmoothedFramerate <Number>`
- `Unlit` / `Lit` / `ToggleUnlit` устанавливает/переключает режим отображения на Unlit или Lit
- `SetGameSpeed <Number>` устанавливает скорость игры

### Меню разработчика

- Нажмите **F6** в игре, чтобы открыть ImGui-меню (статы игрока, камера, визуалы, инспектор сцены и т.д.)
- Клавишу открытия можно переназначить внутри меню в разделе **System**

### Исправления и новые функции:

- Меш игрока теперь соответствует чекпоинтам и типу игры
- Звуки шагов игрока трассируются до первой текстуры, а не до коллизии + трассируются от каждой стопы, а не от центра меша

## Мультиплеер: сервер и клиент

OpenOL поддерживает два способа хостинга:

- **Встроенный relay** — запуск из игры: откройте **Мультиплеер -> Запустить сервер**. Клиенты подключаются через Steam P2P — открытые порты и публичный IP не нужны. Код комнаты: `DEFAULT`.
- **Отдельный relay** — запустите `OpenOL_Relay` (TUI) или `OpenOL_Relay_GUI` (GUI) на любой машине с доступным IP. Клиенты подключаются напрямую по UDP. Код комнаты по умолчанию: `PUBLIC`.

Для подключения к встроенному relay хост приглашает друзей через Steam — клиент принимает приглашение и заходит на сервер автоматически. Для подключения к отдельному relay используйте **Мультиплеер -> Подключиться** с IP:порт и кодом комнаты.

-> [Подробный гайд по серверу и подключению](./docs/MULTIPLAYER_RU.md)

## Сборка

### Linux

Вся компиляция выполняется через `build_wine.sh` (Wine + MSVC 2012). Самый простой способ настроить окружение — автоматизированный скрипт:

```sh
# Укажите нужный путь для Wine prefix, затем запустите:
WINEPREFIX=/path/to/prefix ./Development/Src/Targets/setup_wineprefix.sh
```

Скрипт автоматически скачивает VS 2012 и DirectX SDK и настраивает всё окружение. Затем:

```sh
cd Development/Src/Targets
./build_wine.sh   # интерактивное меню со всеми шагами сборки
```

-> [Полная настройка Linux и решение проблем](./docs/LINUX_RU.md) · [Все шаги сборки](./docs/BUILD_RU.md)

2. Откройте решение, выберите конфигурацию **Release | Mixed Platforms**, соберите

## Упаковка релиза

Чтобы собрать готовый к распространению архив `OpenOL.7z`:

```sh
./Development/Src/Targets/publish_production.sh
```

Результат помещается в `PublishTemp/`. Пользователи могут перетащить содержимое архива в папку Steam-версии игры.
